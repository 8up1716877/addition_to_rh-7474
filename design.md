# Heather's Rubber Hose Studio
Web creative ecosystem, vintage animation meets an editorial professional workspace.
## Palette
Cream #f8f5ed, paper #fffdf8, ink #292920, gold #edbd55, terracotta #ca795c, sage #aeb9a1. Dark mode charcoal and warm paper type.
## Typography
Fraunces expressive display serif + DM Sans body and controls.
## Layout & components
238px persistent sidebar, slim utility header, spacious asymmetric dashboard. Warm outlined paper cards, vintage vector mascots, softly rounded controls. Large exact Welsh hero text. Quick starts, project shelf, inspiration side panel. Responsive stacked mobile view. Clear focus rings and labeled actions.
## Screens and flows
Dashboard, Sketch Studio, Character Creator, Story Studio, Comic Creator, Rubber Hose Lab, Animation Studio, Scene Builder, Voice & Dialogue, Asset Library, Project Manager. Shared components in web/components; page composition in web/pages/index.tsx. Local persistent state, no backend routes needed for approved prototype.
## Prototype boundaries
Browser-local saving. Real drawing and PNG export, character profiles, story writing, comic panel editing and reordering, asset imports. Illustrative animation controls. Explicitly labeled non-live AI and voice previews. No login or cloud sync.
